# BitMatrix · Radical Base & IEEE 754 Converter

A high-performance, cyber-inspired mathematical tool for base conversion and IEEE 754 floating-point analysis.  
Designed for computer architecture students, engineers, and low-level programming enthusiasts.

**100% Client-Side.** No servers. All calculations happen instantly in your browser.

---

### ✨ Why use this?
- Seamlessly convert between **Decimal**, **Binary**, and **Hexadecimal** with step-by-step breakdowns.
- Instantly visualize **IEEE 754 Single (32-bit)** and **Double (64-bit)** floating-point representations.
- Perform arithmetic operations (`+`, `-`, `×`, `÷`) directly on binary and hexadecimal numbers.

---

### 🔧 Key Features
- **🔄 Universal Converter:** Real-time bidirectional conversion between Dec, Bin, and Hex.
- **🧬 IEEE 754 Analyzer:** View the Sign, Exponent, and Mantissa bits for both 32-bit and 64-bit formats.
- **⚙️ Arithmetic Engine:** Add, subtract, multiply, and divide binary or hexadecimal numbers directly.
- **📋 Local History:** Your recent calculations are saved automatically in your browser's local storage.
- **🎮 Cyber-Matrix Aesthetic:** Immersive Matrix rain background with a neon cyberpunk UI.
- **📱 Fully Responsive:** Optimized for mobile, tablet, and desktop environments.

---

### 🚀 Quick Start
1. Enter a number in any of the three fields (**Decimal**, **Binary**, or **Hexadecimal**).
2. The other fields and the **conversion steps** update instantly.
3. Use the **IEEE 754** section to analyze the floating-point representation of any real number.
4. Perform arithmetic operations by entering two numbers, selecting an operator, and clicking the `=` button.

# BitMatrix · MC88

**Convertisseur binaire, hexadécimal, décimal et IEEE 754**


Fonctionnalités

- Conversion entre Décimal, Binaire, Hexadécimal
- Affichage IEEE 754 (32-bit et 64-bit)
- Calculs arithmétiques sur binaire/hexa
- Historique sauvegardé
- Effet **Matrix Rain** desktop site only


Utilisation

Remplissez un champ, les autres se mettent à jour automatiquement.
